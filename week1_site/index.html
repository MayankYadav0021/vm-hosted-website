Integrated LLM Application — Weeks 1 to 4 + Guardrails

Project Progression

This project was developed progressively from VM-based web hosting to a local LLM-powered RAG application with evaluation and guardrails.

Week 1 — VM & Apache

Ubuntu Virtual Machine setup, Apache web server, static website hosting and GitHub integration.

Current Website

Week 2 — Local LLM

Ollama was installed inside the Ubuntu VM. Local code models were downloaded and tested.

View Week 2

Week 3 — RAG Application

FastAPI, embeddings, vector similarity search, knowledge retrieval and local LLM generation.

Open FastAPI

Week 4 — Evaluation

Multiple local models were evaluated using common questions, latency, token usage and quality metrics.

View Week 4

Guardrails

Input validation, prompt-injection filtering and output validation were added to the LLM application.
