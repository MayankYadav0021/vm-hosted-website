Week 1 — VM & Apache Hosting

Virtual Machine Setup, Web Hosting and GitHub Integration

Objective

Week 1 focused on setting up an Ubuntu Virtual Machine, hosting a static website using Apache2, and connecting the project with GitHub.

What Was Implemented

  • Ubuntu Virtual Machine using Oracle VirtualBox
  • Apache2 web server installation
  • Static HTML website
  • Website hosted inside the VM
  • Git and GitHub repository integration
  • Project changes committed and pushed to GitHub
