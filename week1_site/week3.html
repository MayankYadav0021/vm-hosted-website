Week 3 — RAG Application

FastAPI + Embeddings + Retrieval-Augmented Generation

Objective

Week 3 transformed the local LLM setup into a working software-project question answering application using Retrieval-Augmented Generation (RAG).

RAG Pipeline

User Question
↓
Query Embedding
↓
Vector Similarity Search
↓
Top-K Relevant Chunks
↓
Retrieved Context
↓
Local LLM
↓
Grounded Response

Knowledge Base

The project knowledge base contains:

  • README.md
  • architecture.md
  • authentication.md
  • api.md

Documents are divided into chunks, converted into embeddings, and searched using cosine similarity.

API Endpoints

GET /health — Checks API and Ollama status.

POST /api/chat — Direct LLM response without retrieval.

POST /api/rag — Retrieves project context before generating the response.
